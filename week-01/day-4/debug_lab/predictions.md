# Predictions (پیش‌بینی قبل از اجرای save_day.sh)

فرض‌ها: توی پوشه این فایل‌ها هست: .env و .venv/ و a.txt
و msg برابره با: feat(week-01): add card

## 1. کدوم فایل‌ها وارد Staging می‌شن؟
اول git add -A اجرا می‌شه و بعد .gitignore ساخته می‌شه.
یعنی موقع add کردن هنوز لیستی وجود نداره که بگه چی رو نذار.
پس فکر می‌کنم همه فایل‌ها وارد Staging می‌شن: .env و .venv/ و a.txt
و این یعنی رمزها هم تو Staging هستن.

## 2. پیام Commit چی می‌شه؟
$msg کوتیشن نداره، پس Bash اون رو سر فاصله‌ها می‌شکنه.
Git می‌بینه: git commit -q -m feat(week-01): add card
فقط کلمه‌ی اول بعد از -m پیام حساب می‌شه.
add و card رو Git فکر می‌کنه اسم فایلن.
پس فکر می‌کنم Commit خطا می‌ده و ساخته نمی‌شه.

## 3. Push چی می‌شه؟
اسکریپت به شاخه‌ی master Push می‌کنه ولی شاخه‌ی ما main ـه.
پس فکر می‌کنم Push خطا می‌ده و چیزی به GitHub نمی‌ره.

## 4. آخرش چی چاپ می‌شه؟
اسکریپت set -e نداره، یعنی بعد از خطا متوقف نمی‌شه.
آخرین خط echo ـه و echo همیشه موفق می‌شه.
پس فکر می‌کنم باز هم این رو چاپ کنه: saved week-01/day-4
و کد خروج هم صفر باشه، یعنی همه فکر می‌کنن کار موفق بوده.
